# Prestige Realty Estate

Prestige Realty Estate is a modern and fully responsive real estate website built using HTML, CSS, and JavaScript. The website is designed to provide an attractive and user-friendly platform for showcasing real estate properties and services.

## 🚀 Live Demo

https://prestigerealtyestate.netlify.app/

## ✨ Features

- Fully responsive design
- Modern and clean user interface
- Smooth navigation experience
- Property showcase sections
- Contact section for inquiries
- Fast loading and lightweight
- Cross-browser compatibility

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
